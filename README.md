# IBM HR Analytics Project

## Project Overview
This project focuses on analyzing employee attrition data to identify the major factors affecting employee turnover in an organization. The analysis was performed using Python, SQL, and Power BI to generate meaningful insights and interactive dashboards.

The main goal of this project is to help organizations understand employee behavior and improve retention strategies through data-driven decisions.

---

## Objectives
- Analyze employee attrition trends
- Identify factors affecting employee turnover
- Perform data cleaning and preprocessing
- Create visual dashboards for better insights
- Generate business recommendations

---

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI
- Jupyter Notebook

---

## Dataset Information
The dataset contains employee-related information such as:
- Age
- Department
- Job Role
- Salary
- Education
- Job Satisfaction
- Years at Company
- Overtime
- Attrition Status

---

## Project Workflow

### 1. Data Cleaning
- Removed missing/null values
- Checked duplicate records
- Converted data types
- Handled inconsistent data

### 2. Exploratory Data Analysis (EDA)
- Attrition analysis by department
- Salary vs attrition
- Overtime impact on attrition
- Job satisfaction analysis
- Age group analysis

### 3. Dashboard Creation
Interactive dashboards were created in Power BI to visualize:
- Employee attrition rate
- Department-wise attrition
- Salary distribution
- Job role analysis
- Employee demographics

---

## Key Insights
- Employees working overtime showed higher attrition rates.
- Lower salary employees were more likely to leave.
- Certain departments had significantly higher attrition.
- Job satisfaction played an important role in employee retention.
